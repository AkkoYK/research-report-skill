1. 摘要与范围

本示例演示如何在书面报告中组织摘要、方法和结果。正文、表格和图形使用统一的字体与配色，读者可以从简要结论继续查看数据和解释。

表 1 使用三类虚构资料演示核验结果：共 100 份资料，其中 94 份包含全部必填信息，完整率为 94.00%。这一数值说明信息是否齐全；资料内容的准确性需要另行核查。

2. 方法说明

方法部分交代资料如何进入分析，以及采用了哪些判断标准。说明收集范围、核验步骤和结果记录方式，有助于读者理解表格中每个数值的含义。

2.1 明确核验规则

正式报告中应写明资料日期、纳入范围、必填信息和缺失值处理方式。同一张表中的资料采用一致规则，分类依据与例外情况放在结果旁说明。

2.2 让结论能够对应证据

重要结论给出图表或资料入口。正文说明与判断直接有关的依据，完整清单、逐项记录和补充说明可放在附录。标题直接说明内容，段落围绕一个问题展开。

3. 版式要点

本页使用 10.5 pt 正文、1.75 倍行距和三线表。主标题、章节标题、图表说明各有固定层级，左右边界对齐。较长标题与表头优先通过调整文字和列宽处理。

4. 图形与流程说明

图 1 说明资料处理的先后顺序。图内字体、线条和配色与正文一致，箭头表示明确的流程关系。图形源文件可以单独导出，并在不同文档中调整使用尺寸。

图形为本模板绘制的排版示例，表示逻辑顺序。图题置于图下，编号在正文中引用。

5. 资料与依据

读者需要知道结果如何得到，以及去哪里查看细节。短表可以集中说明这些信息，完整清单和原始资料可作为独立附件保存。

6. 文件导出

修改正文后，重新检查每页的内容高度、表格换行和图内文字。导出 PDF 时使用 A4 页面与实际字体，重新打开保存后的文件，确认图表、页码、链接和书签。

本示例采用固定分页。添加内容时应同步调整页数与页脚；配套 CSS 保留溢出显示，便于在导出前发现内容超出页面的问题。
