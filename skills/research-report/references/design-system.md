# 书面报告设计系统

适用于无指定版式的正式中文报告。接收方要求优先；字体、尺寸与颜色均为可调默认值。

## 页面与字体

白底、单栏、左对齐。标题、段落、表格和图形共享对齐边界；使用字号、字重和间距组织层级。

| 元素 | 默认参数 | 调整要点 |
|---|---|---|
| 页面 | A4，210 × 297 mm | 装订、批注或接收方要求可改变边距 |
| 边距 | 上 17.7 mm，其余约 16.7 mm | 最终按实际打印尺寸检查 |
| 字体 | PingFang SC，回退至 Noto Sans CJK SC、思源黑体、微软雅黑 | 替换字体后重新检查分页 |
| 正文 | 10.5 pt，行距 1.75，段后 3 mm | 默认无首行缩进；调整后全篇统一 |
| 文档主标题 | 23 pt，字重 600，行距 1.4，段后 5 mm | 长标题可调整换行 |
| 一级章节标题 | 14 pt，字重 600，行距 1.5 | 段前 6 mm，段后 3 mm |
| 二级章节标题 | 11.5 pt，字重 600，行距 1.5 | 段前 4 mm，段后 2 mm |
| 文档信息行 | 9.8 pt | 只保留版本、日期等必要信息 |
| 表格 | 9.3 pt，行距 1.6 | 优先调整文字和列宽 |
| 表题 | 10 pt，字重 500，居中 | 置于表上方 |
| 图题 | 9.6 pt，行距 1.6，居中 | 置于图下方 |
| 参考资料 | 9 pt，行距 1.65 | 长链接可换行 |
| 页眉与页码 | 6.75 pt | 打印需要时调至 8 pt 并复查布局 |

正文层级通常控制在三级以内。短报告可让标题、摘要与正文直接衔接；长报告按阅读需要增加封面与目录。标题与首段、图形与图题保持相邻。章节末页和参考资料末页允许自然留白。

苹方是本套风格的首选字体，模板不分发字体文件。应从渲染结果确认实际字体，不能仅凭 CSS 声明判断加载成功。

## 配色

| 用途 | 色值 |
|---|---|
| 正文、标题、表格主线 | `#172033` |
| 次要说明与图题 | `#3D4A63` |
| 文档信息 | `#526076` |
| 页眉与页脚 | `#68768B` |
| 链接与图表系列一 | `#2256B5` |
| 图表系列二 | `#0E9C8A` |
| 辅助分隔线 | `#DFE4EB` |
| 补充区浅背景 | `#F7F8FA` |

同一对象在全文中保持同色。图表同时使用标签、标记或线型区分对象，兼顾灰度阅读。正文不需要大面积色块、卡片阴影和装饰图标。

## 三线表

使用顶线、表头下横线和底线：上下主线默认 1.1 pt，表头线 0.6 pt。普通行无横线，单元格无竖线，默认白底。

单元格上下留白 2 mm、左右 1.8 mm。文字列左对齐，数值列及表头右对齐；同类数据使用一致精度。单位写在表头，例如“数量 / 份”“长度 / cm”“比例 / %”；缺失值与统计条件写在表注。

表题在上，编号如“表 1　资料核验结果”，正文引用同一编号。短表整体放在一页；长表跨页时重复表头、标注续表，避免拆开同一数据行。宽表按信息关系拆分或使用横向页。

HTML 使用原生 `table`、`thead`、`tbody`、`caption` 和明确列宽；DOCX 使用原生表格；LaTeX 可采用 `booktabs`。修改应回到表格源文件。

## 图形与图表

根据需要解释的关系选择图形：组成关系可用结构图，执行顺序可用流程图，变化可用折线图，数量比较可用柱状图。

图内标签与图题应足以解释图意，标明数据来源及必要条件。字体和单位与全文统一；图内文字按最终插入尺寸检查，默认至少约 9 pt。避免用缩小整页演示材料的方式获得报告插图。

保留图形源文件。示意图、细线图优先使用 SVG 或其他矢量格式；位图以最终插入尺寸核对清晰度，一般彩图可从约 300 DPI 开始检查。接收方要求更高分辨率时按要求处理。

柱状图默认从零开始。折线图采用局部范围或非等距时间时明确标注，必要时提供全局视图。坐标、图例与正文不能对同一数据使用冲突的定义。

## 页面检查

检查最终文件的所有页面，包括封面、目录、附录和参考资料。确认没有截断、重叠、孤立标题、异常大空白或难以辨认的文字；图表与说明相邻，编号、链接及页码一致。调整字号、字体或列宽之后重新导出检查。
