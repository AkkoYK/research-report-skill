# 正文、证据与表达

## 建立内容结构

按读者需要作出的判断组织报告。摘要概括目的、方法、主要发现和适用范围；正文解释结论如何得到。篇幅较短时可合并章节。

| 内容 | 需要回答的问题 |
|---|---|
| 背景与问题 | 为什么开展这项工作，已有资料说明了什么 |
| 目标与范围 | 研究对象、约束与评价标准是什么 |
| 方法或方案 | 如何获得证据，为什么选择这种方法 |
| 结果 | 观察到或完成了什么 |
| 分析与讨论 | 结果如何解释，哪些条件影响判断 |
| 结论与建议 | 哪些判断已有依据，后续事项是什么 |
| 参考资料与附录 | 去哪里查看来源、细节与完整记录 |

方案报告可以先介绍需求和备选方案；项目总结可以按目标及其完成证据组织。无需把这些标签逐一变成章节，也无需为没有材料的章节补写概括性段落。

## 证据与来源

重要陈述应能对应资料位置、数据或明确分析。整理材料时可建立工作清单，记录“结论、来源位置、获得条件、核验状态”；是否随报告交付由任务决定。

- 区分来源直接给出的数据、自行计算的结果和分析解释。
- 计算数据时记录公式、分母、单位及取舍方式，并核对原始输入。
- 不同条件下的数据分别标注，避免直接放在同一尺度上作无条件比较。
- 记录足以影响解释的时间、样本范围、误差或其他限制。
- 未确认的信息保持待核实，不补造来源或具体结果。
- 模板中的虚构示例只演示格式，不能转成正式报告的事实。

选择汇总方法时先判断它回答的问题。使用比例说明基数；使用平均值说明方式与权重。没有分布或原始记录时，不凭空补写置信区间、显著性或稳定性结论。

引用按接收方的格式统一处理。无指定要求时可使用顺序编号，列出作者或机构、标题、年份或版本、可定位链接；网页可补访问日期。转绘图和引用数据标明来源，保留应有归属。

## 正式而自然的中文

句子写清对象、动作、条件与结果。术语第一次出现时，按读者背景解释其含义；同一概念保持同一名称。原因与结论之间有中间步骤时，应交代实际关系。

描述具体工作和发现，结论力度与证据相称。保留有依据的贡献及其适用范围，减少空泛形容词、同义反复和反复辩解。

示例数据可以支持：“共核验 100 份资料，其中 94 份包含全部必填信息，完整率为 94.00%。”这说明资料完整程度；是否达到目标，需要同时提供目标值和范围。资料内容是否准确，则需要另一项核查。

连续因果关系用自然段，并列条件、步骤或检查项可用列表。标题直接说明内容。避免每句话单独成段、整段加粗、机械对称标题和没有增加信息的收尾总结。

保持自然语法。删除冗余时保留承担条件、指代和关系的虚词；不要把完整句子压缩成含义模糊的术语串。

## 交付核对

核对摘要与正文是否一致，重要数字和引用能否定位，推断是否被写成事实。朗读主要段落，检查指代、长句关系及重复表述。交付文件只包含真实材料及明确标注的示例，临时标记在交付前处理。
